# REST API для объявлений на aiohttp

Учебный проект, реализующий CRUD‑операции для объявлений на асинхронном фреймворке aiohttp.

## Функциональность

* Создание объявления (`POST /ads`)
* Получение объявления по ID (`GET /ads/{id}`)
* Частичное обновление (`PATCH /ads/{id}`)
* Удаление объявления (`DELETE /ads/{id}`)
* Валидация данных (заголовок 1–200 символов, описание и владелец не пустые)
* Корректная обработка ошибок (400, 404)
